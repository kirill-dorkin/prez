# Сайт-презентация к 4 занятию

Тема: HTML как план страницы.

Откройте `index.html` в браузере.

Управление:

- стрелки влево/вправо - переключение слайдов;
- пробел - следующий слайд;
- `F` - полный экран;
- `T` - подсказка преподавателю;
- `?` - горячие клавиши.

Внутри:

- `index.html` - сама сайт-презентация;
- `styles.css` - оформление;
- `app.js` - навигация и интерактив;
- `LESSON.md` - подробный план проведения урока на 90 минут;
- `examples/teacher-demo.html` - простой пример HTML-каркаса для демонстрации.
