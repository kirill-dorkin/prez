# Проверка

Проверено перед выдачей:

- презентация открывается как обычный `index.html` без сборки;
- внешних зависимостей нет;
- 15 экранов;
- стрелки, пробел, свайп, `F`, `T`, `?` предусмотрены;
- тёмные блоки кода убраны;
- длинные тире не используются;
- финальный экран объединяет результат урока, чеклист и мостик к CSS;
- есть отдельный план занятия на 90 минут;
